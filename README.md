# PortalIris

PortalIris enables real-time data aggregation and processing through a High-Performance, Distributed-Compute architecture.

PortalIris is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/PortalIris.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

PortalIris is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
